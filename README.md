# ANI-Gamut

Project home page for **ANI-Gamut** — *Benchmarking Agent Reliability across the
Gamut of Agent–Network Interface Abstractions*.

The site is a GitHub Pages site (Jekyll, `pages-themes/slate` remote theme) served
from the **`docs/`** folder.

- **Live site:** `https://netgroup.github.io/ani-gamut/`
- **Source:** `docs/` — `_config.yml`, `index.md`, and `assets/` (figure + CSS override).

To publish: GitHub repo → *Settings → Pages → Deploy from a branch → `main` / `docs`*.
